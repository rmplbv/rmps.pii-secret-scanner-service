# Species allow list: animal, plant and fungus names plus nature-conservation
# vocabulary that must NOT be redacted as PII. NER models frequently mis-tag
# species names as PERSON / LOCATION / ORGANIZATION (e.g. "Kiebitz" -> LOCATION,
# "Lapwing" -> PERSON); entries here suppress those false positives.
#
# Format:
#   - One name per line; multi-word names are allowed
#     (e.g. "Großer Brachvogel", "Eurasian Curlew", "Numenius arquata").
#   - Matching is case-insensitive on the WHOLE detected span.
#   - Lines starting with "~" mark names that are ALSO common surnames or given
#     names (e.g. ~Fink, ~Specht, ~Adler, ~Wolf, ~Robin, ~Martin, ~Swift).
#     For these the service will NOT suppress PERSON detections; LOCATION /
#     ORGANIZATION false positives are still suppressed.
#   - Lines starting with "#" are comments; "# --- ... ---" lines group sections.
#   - Blank lines are ignored.
#   - No duplicates (case-insensitive).
#
# Deliberately excluded: real place names (e.g. regions, lakes, moors, towns
# that share a name with a species or tree). Places can identify where people
# live or work and must stay detectable.
